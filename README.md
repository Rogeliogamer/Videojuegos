### 📺 100 Mexicanos Dijeron - Juego Web Multijugador
**Descripción:** Adaptación full-stack en tiempo real del popular programa de televisión. Diseñado con arquitectura cliente-servidor Serverless utilizando React y AWS DynamoDB.
* **Características Clave:** Gestión asíncrona de salas mediante PIN único, sincronización en tiempo real entre el panel del Host y los dispositivos de los jugadores, y un motor de validación del lenguaje natural (NLP) para respuestas.
* **Stack Tecnológico:** React, JavaScript, AWS SDK, DynamoDB, Docker.
